# Git commits

- Never add `Co-Authored-By` or other attribution trailers to commit messages.
- Use Conventional Commits (`feat:`, `fix:`, `chore:`, `ci:`, `build:`, `style:`, …).
- Keep commit messages simple, short, and precise.
- Write the description after the type in sentence case, e.g. `ci: Add Docker image build pipeline`.
- Sign commits if possible.
